# Joselyn Portorreal — personal website

My professional site for RESECON 490AI (Fall 2026): Home, About, Projects, Résumé, Contact.
Plain HTML and CSS, no JavaScript, no build step. Built with Claude Code (anti-slop-web skill); content and decisions are mine.

## How to open it
Double-click `index.html` in Finder. It opens in your browser; use the menu to move between pages.

## Files
- `index.html`, `about.html`, `projects.html`, `resume.html`, `contact.html` — the five pages
- `styles.css` — all colors, fonts and layout (colors are at the top)
- `favicon.svg` — the "JP" icon in the browser tab

## Still placeholder
Search the folder for `[PLACEHOLDER]`:
- Photo (Home) — add `photo.jpg` to this folder
- Résumé PDF (Résumé page) — add a web-safe `resume.pdf` (no phone number or home address)
- Project summary and the report / slides / charts links (Projects)
- A personal sentence (About), Baystate day-to-day line and RA dates (About)
- GitHub and LinkedIn links (Contact)

## Publish (GitHub Pages)
Upload everything **inside** this folder (not the folder itself) to the repository `USERNAME.github.io`,
so `index.html` sits at the top. The site appears at `https://USERNAME.github.io` in 1–2 minutes.

## Privacy
Never add: phone number, home address, student ID, GPA, transcript.
